# alu-higher_level_programming

## JavaScript - Warm up

### Description

This directory contains a set of beginner JavaScript scripts covering the language's core building blocks: variables, data types, and console output. Each script is written to comply with the `semistandard` linter, which enforces a consistent, clean JavaScript style without requiring semicolons on every line.

### Requirements

- All scripts are interpreted/compiled on Ubuntu 20.04 LTS using Node.js (version 14.x or later)
- All files end with a new line
- A `README.md` file, at the root of the project folder, is mandatory
- The first line of all files should be a comment explaining the script's purpose (where applicable) and begin with `#!/usr/bin/node`
- All code should use the `const` and `let` keywords — `var` is not allowed
- All code should pass `semistandard` (with no warnings)
- To test `semistandard`, run: `semistandard file_name.js`

### Tasks

| # | File | Description |
|---|------|-------------|
| 0 | `0-javascript_is_amazing.js` | Defines a constant `myVar` and prints "JavaScript is amazing" using `console.log` |

### Usage

Each script can be run directly from the command line:

```bash
./0-javascript_is_amazing.js
```
