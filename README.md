# alu-higher_level_programming

This repository contains projects from the Higher-Level Programming track of the ALX Software Engineering program. It covers a range of topics across Python, SQL, and JavaScript, moving from foundational syntax to more advanced language features and best practices.

## Projects

| Directory | Description |
|-----------|-------------|
| `SQL_introduction` | Introductory SQL — creating databases, tables, and running basic queries |
| `SQL_more_queries` | More advanced SQL — joins, filtering, aggregation, and multi-table queries |
| `javascript-warm_up` | JavaScript fundamentals — variables, data types, and console output |
