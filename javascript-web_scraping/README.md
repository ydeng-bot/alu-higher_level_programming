# alu-higher_level_programming

## JavaScript - Web scraping

### Description

This directory covers reading, writing, and requesting data with Node.js — working with the file system module (`fs`) synchronously and asynchronously, and making HTTP requests to fetch data from the web.

### Requirements

- All scripts are interpreted/compiled on Ubuntu 20.04 LTS using Node.js (version 14.x or later)
- All files end with a new line
- A `README.md` file, at the root of the project folder, is mandatory
- The first line of all files should begin with `#!/usr/bin/node`
- All code should use the `const` and `let` keywords — `var` is not allowed
- All code should pass `semistandard` (with no warnings)
- To test `semistandard`, run: `semistandard file_name.js`

### Tasks

| # | File | Description |
|---|------|-------------|
| 0 | `0-readme.js` | Reads and prints the content of a file (async, utf-8), or prints the error object if reading fails |

### Usage

```bash
./0-readme.js cisfun
```
